# Create: Bigger Storage Continued 1.2.0

**测试版** — Minecraft **1.20.1**，Forge **47.4.10 及以上（47.x）**，Create **6.0.6～6.0.8**，Java **17**。

## 兼容性

- 新增对 Create **6.0.6、6.0.7、6.0.8** 的兼容，使用同一安装包。
- 最低 Forge 版本调整为 **47.4.10**。

## 优化

- 优化大型保险库的槽位定位，减少终端频繁存取、合成时的库存查找开销。

## 修复

- 内置 **Flywheel 1.0.5**，引入间接渲染实例并行更新时数组越界异常的上游修复。

## 安装

- 关闭游戏或服务器后替换旧版模组文件；客户端与服务端使用相同版本。
- 仅保留一份本模组，不要同时安装原版 Bigger Storage 或其 Create 6 桥接补丁。
- 安装包已包含 **Flywheel 1.0.5**，无需额外安装该依赖。
- **Create: Connected** 为可选依赖，仅在使用原版档位的纵向保险库及相关升级时需要；请选用与当前 Create 版本兼容的版本。
- 更新前备份存档，建议先在存档副本中确认运行正常。
