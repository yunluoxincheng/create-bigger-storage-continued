# Create: Bigger Storage Continued 1.2.0

**Beta / 兼容候选版** — Minecraft 1.20.1, Forge 47.4.10+, Create 6.0.6–6.0.8, Java 17.

## Changes / 更新内容

- One mod jar targets Create 6.0.6, 6.0.7 and 6.0.8, compiled against the lowest supported Create release.
- Supply Flywheel 1.0.5 through Forge Jar-in-Jar and require that backend version on clients. This includes the upstream fix for the indirect-instancer array-index exception loop, including when Create 6.0.6 itself bundles Flywheel 1.0.4.
- Move the Forge development/minimum baseline to 47.4.10. Registrate remains unchanged; development Ponder matches the minimum Create baseline, while newer Create releases supply their matching Ponder.
- Use Create's equal-size combined inventory wrapper for direct slot-to-member lookup. Unequal member capacities fall back to the ordinary wrapper.
- Retain 1.1.2 notification coalescing, inventory persistence, registry IDs, capacities, recipes, translations, artwork and upgrade transactions.

三版Create共用一个安装包，内嵌Flywheel 1.0.5，开发与最低Forge基线为47.4.10。核心库存代码只替换合并包装器，原有通知与同步优化保留。

## Verification / 验证范围

Local Java compilation, bundled-jar construction and Forge reobfuscation passed. Forge/Registrate development initialization and data generation passed separately with Create 6.0.6, 6.0.7 and 6.0.8; generated resources were unchanged. Forge's actual JarSelector selected exactly one Flywheel 1.0.5 from each official Create distribution plus the final mod jar.

These checks do not establish production-client rendering, terminal operations, inventory upgrades, save/reload or contraption gameplay acceptance. No measured FPS/TPS gain is claimed. See `COMPATIBILITY_1_2_0.md` for the precise boundary.

三版初始化与真实依赖解析通过，不将其等同于游戏内完整验收。1.1.2已收到用户实测无明显问题的反馈，1.2.0仍待独立游戏验收。

## Installation / 安装

Stop the client/server before replacing the mod. Install the full, ordinary-named 1.2.0 jar on both sides, use Forge 47.4.10+ and Create 6.0.6, 6.0.7 or 6.0.8, and keep only one `create_bs` mod. The full jar supplies the fixed Flywheel library; do not install the internal `-unbundled` artifact. Use a save copy for initial verification.

Create: Connected remains optional for the standard vertical silo and upgrades involving it. Choose a Connected version compatible with your Create release; newer Connected releases can require Create 6.0.8. Connected combinations have no new gameplay acceptance here.

Flywheel remains an original nested MIT-licensed library with its notice intact. Bigger Storage and Create code/artwork attribution is preserved.
