# Create: Bigger Storage Continued 1.2.1

**Beta** · Unreleased

Minecraft **1.20.1** · Forge **47.4.10+ (47.x)** · Create **6.0.6–6.0.8** · Java **17**

## Added

- Add manually controlled vault diagnostics with `/create_bs diagnostics start`, `status` and `stop` to inspect inventory queries, summary rebuilding, copying and package flow.

## Changed

- Replace the previous AI-derived mod icon with a composition of the current iron and copper vault textures.

## Performance

- Resolve threshold-switch inventory compatibility once per scan, reducing repeated checks for large vaults.
- Share stock summaries across packagers using the same vault and rebuild changed summaries from dirty slots and affected item groups. Idle caches release temporary data without changing stored items.
- Defer independent summary copies until public queries, arrival tracking or saved stock baselines need them, and reduce temporary bookkeeping on unchanged stock checks.
- Reduce temporary NBT-copy allocations when independent package summaries are needed, retaining complete item tags and native capability handling.
- Stop further source scanning once an ordinary packager fills a package for an eligible simple vault order, preserving extraction accounting and order metadata.

## Fixes

- Prevent controller lookup during capability invalidation from modifying the block-entity collection, addressing client chunk-refresh exceptions and broken vault connected textures.

## Installation


- Stop the game or server before replacing the old JAR, and install the same version on both sides.
- Use Create **6.0.6, 6.0.7 or 6.0.8** and Forge **47.4.10 or newer within 47.x**. Flywheel **1.0.5** is included; no separate download is required.
- This mod replaces the original Bigger Storage. Keep only one `create_bs` mod; do not install the original mod or the `createbiggerstoragetocreate6` bridge patch alongside it.
- Create: Connected is optional and needed only for the standard-tier vertical silo and upgrades involving it. Select a compatible Connected release; its upstream compatibility table lists Create **6.0.6** as unsupported.
- Back up your world before updating.
