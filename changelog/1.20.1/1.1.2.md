# Create: Bigger Storage Continued 1.1.2

**Stable / 正式版** — Minecraft 1.20.1, Forge 47.2.32, Create 6.0.4, Java 17.

Promoted to stable following explicit user acceptance on 2026-10-13. The existing `v1.1.2` tag and all build artifacts are preserved. The attached verification record describes the initial beta build; this promotion changes release status and documentation only.

用户于2026-10-13确认1.1.2可作为正式版。本次沿用原标签及全部构建附件，不补记未单独完成的性能或兼容测试。

## Changes / 更新内容

- Coalesce inventory-driven comparator notifications at the vault controller's tick, rather than notifying the entire structure on every slot mutation.
- Cache comparator output until inventory, structure or inventory capability changes invalidate it.
- Mark each changed member's chunk for saving immediately and coalesce repeated marks within a tick; retain complete inventory NBT in world saves.
- Opaque vaults no longer request client updates for inventory mutations or include inventories in client structure/chunk synchronization.
- Crystal vaults synchronize only the local slots used by their existing internal item renderer, with changes coalesced at the member's tick. Item counts, NBT and render positions are retained.
- Server inventory access, capacities, registry IDs, upgrade transactions, recipes, translations and textures remain unchanged.

合并整组库存通知，缓存比较器读数，普通保险库移除无用库存同步，水晶保险库仅同步可见槽位。存档仍保存完整库存，终端读写仍即时生效。

## Behavior and verification / 行为与验证

Comparator notifications may wait until the next controller tick, and intermediate inventory states within one tick are coalesced. Terminal inventory mutations remain immediate.

Local Java compilation, jar construction, Forge reobfuscation and resource comparisons passed. In-pack performance, Tom's Storage / AE / RS terminal compatibility, comparator behavior, crystal rendering and save/reload acceptance remain pending. No measured FPS/TPS improvement is claimed. GitHub Actions build success verifies the tagged build; it does not establish in-game acceptance.

比较器通知可能延后到下一次控制器tick，同tick中间状态合并。此版本尚待整合包性能与游戏内验收。

## Installation / 安装

Stop the client/server before replacing the old jar. Load only one `create_bs` mod; do not also install original Bigger Storage or its Create 6 bridge patch. Use the same version on client and server. Test a save copy first. Create: Connected is required only for the standard vertical silo and upgrades involving it.

Unofficial continuation of LopyLuna's Bigger Storage. Code attribution and MIT notices are preserved; vault textures derive from Create's MIT artwork and component icons are drawn in Python.
