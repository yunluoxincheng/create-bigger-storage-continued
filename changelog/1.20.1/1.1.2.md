# Create: Bigger Storage Continued 1.1.2

**Stable** · Released 2026-10-13 (UTC)

Minecraft **1.20.1** · Forge **47.2.32+ (47.x)** · Create **6.0.4** · Java **17**

## Performance

- Coalesce repeated comparator notifications from inventory changes into one update per vault controller tick, reducing repeated work during frequent item transfers and crafting.
- Cache comparator readings until inventory, structure or inventory capability changes require recalculation.
- Remove inventory data from opaque vault client synchronization and avoid requesting client updates for inventory-only changes.
- Synchronize only the slots used to display items inside crystal vaults, coalescing repeated changes per member tick while preserving displayed item counts, NBT and positions.
- Coalesce repeated chunk save marks within a tick while still marking changed inventories for saving immediately.

## Changed

- Comparator notifications are processed on the next controller tick; intermediate inventory states within that tick are combined. Terminal inventory reads and writes remain immediate.

## Installation

- Stop the game or server before replacing the old JAR, and install the same version on both sides.
- Use Create **6.0.4** and Forge **47.2.32 or newer within 47.x**.
- This mod replaces the original Bigger Storage. Keep only one `create_bs` mod; do not install the original mod or the `createbiggerstoragetocreate6` bridge patch alongside it.
- Create: Connected is optional and needed only for the standard-tier vertical silo and upgrades involving it. Choose a release compatible with Create 6.0.4.
- Back up your world before updating.
