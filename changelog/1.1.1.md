# Create: Bigger Storage Continued 1.1.1

Minecraft 1.20.1, Forge 47.2.32, Create 6.0.4, Java 17.

## Changes / 更新内容

- Final material-colored vault textures retain Create's panel patterns, frames and connected-texture atlas structure.
- Translucent blue crystal panels have the small side rivet dots removed.
- Retain the native 16×16 Python-drawn component and upgrade icons.
- Allow a complete 3×3 cross-section to regroup independently from an older narrow vault, keeping inventories owned by each block while remaining members regroup normally.
- Exclude 30 retired, unreferenced construction-layer textures from the runtime jar.

最终材质保留Create板面纹理并按材料配色，水晶采用半透明蓝色并移除侧面小点；修复完整3×3截面无法从旧2×2结构独立重组的问题。

## Verification / 验证范围

The user accepted the final visuals and connectivity repair in an independent client. Local builds and resource verification passed. Large-inventory cross-section regrouping, save/reload and other compatibility scenarios have no separate complete acceptance record. The public CI build uses the approved 1.1.1 source snapshot with release automation added; build bytes need not match the historical local jar.

本版保留用户对材质和连接修复的接受记录，不补记未单独完成的兼容与大量库存验收。

## Installation / 安装

Stop the client/server before replacing the old jar. Load only one `create_bs` mod; do not also install original Bigger Storage or its Create 6 bridge patch. Create 6.0.4 is required. Create: Connected supplies the standard vertical silo.

Unofficial continuation of LopyLuna's Bigger Storage. Code attribution and MIT notices are preserved; vault textures derive from Create's MIT artwork and component icons are drawn in Python. The public repository starts with this current-artwork snapshot and omits old local history containing upstream ARR artwork.
