# Changelog

Each tagged version has a separate release note used by the GitHub release workflow.

## Minecraft 1.20.1

- [1.2.0 — Create 6.0.6–6.0.8 and fixed Flywheel backend (beta)](changelog/1.20.1/1.2.0.md)
- [1.1.2 — Inventory notification and synchronization optimization (stable)](changelog/1.20.1/1.1.2.md)
- [1.1.1 — Final textures and vault cross-section merging](changelog/1.20.1/1.1.1.md)

New tags use `mc<Minecraft>-v<mod>`, for example `mc1.20.1-v1.1.3`.
The published `v1.1.1` and `v1.1.2` tags and their original release notes remain
historical records. Each Minecraft branch advances its mod versions independently.

Earlier local artifacts are retained locally. No 1.1.0 source tag is claimed: its
exact accepted source snapshot was not separately committed. Public version
history starts with the verified 1.1.1 source tree.
