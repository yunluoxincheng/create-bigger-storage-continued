# Python原创升级组件样张

按用户要求，由Python/Pillow在16×16像素网格上独立绘制；没有调用图像生成，没有读取现成图标作为绘图输入。

本机Create 6.0.4的铁板、黄铜板及精密构件仅用于观察风格：低饱和材质色、左上高光、下缘暗面和少量黄铜连接件。原版参考图片保存在Git忽略的build目录，不在本样张包中。

四个PNG是木质→原版、原版→铁、铁→金、钻石→下界合金。共用同一种结构：较小的来源薄板在左后方，较大的目标薄板在右前方，两枚黄铜接头连接，向上箭头表示升级。实际图标最多16种不透明颜色，Alpha为0/255。

2026-10-09按用户反馈为薄板主体增加固定的深浅像素色块：左上少量亮块、右下阴影和两处较亮磨损点。只修改原来的面板底色像素，轮廓、透明度、黄铜接头及箭头保持原样；没有随机噪点、平滑渐变或抗锯齿。原平滑样张及绘图脚本保存在Git忽略的 `build/python-upgrade-flat-v1/`。

随后按用户反馈将箭头改为目标档位的材质色：原版蓝灰、铁银灰、金金色、下界合金灰褐。箭头复用目标薄板的亮色、底色与暗色，左上高光、右侧和底端阴影；只改原箭头的11个填充像素，薄板、接头、箭头形状与描边不变。之前的白箭头样张和脚本保存在Git忽略的 `build/python-upgrade-shaded-white-arrow-v2/`。

再次按用户反馈将箭杆向下延长2个原生像素，箭头下方的箭杆从2像素变为4像素；暗色端点移到新底端，目标材质配色与箭头头部不变。旧短箭杆样张及脚本保存在Git忽略的 `build/python-upgrade-short-target-arrow-v3/`。

`samples.png` 展示放大图和32屏幕像素小样；`samples-target-arrow.png` 保留上次短箭杆预览，`samples-long-arrow.png` 是本次长箭杆预览。四个独立PNG是可用的原生16×16文件。`upgrade-icon-samples.zip` 含四个PNG及记录。绘图代码为 `tools/DrawUpgradeIconSamples.py`。

当前仅用于审阅样式，未替换游戏/模组资源、未打包到模组、未提交Git。
